Observability

What the retriever did, and why an answer said what it said. Every figure on this page is counted from real events, not estimated. Nothing here is shown to a client or to any agency.

Reachability

Each of these makes ONE real call when you press the button. A reachability check that does not make a request checks nothing.

The library

Documents in the index, and how many passages carry a vector. A document with passages but no vector is findable by wording only, and says so on its row in Documents.

Ask the retriever directly

This runs the SAME search the assistant runs, with no model involved, and shows which retriever found each passage: keyword for shared words, semantic for meaning, both when the two agreed. Fusion promoting something neither list ranked highly is the behaviour hybrid search is bought for.

The last 50 questions

Read from the usage record in the bucket, not from this instance's memory, so a question answered five minutes ago by another instance is here too.

Activity

Counted from the same record. A document nobody has ever retrieved is dead weight worth reviewing, not necessarily worth deleting.

Settings in force

The numbers the retriever is actually running with, read from the code rather than typed here, so this page cannot claim a parameter the system is not using.
